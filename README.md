# 像素算力鎮（PixelCompute Town）MVP 原型

將閒置的 **API 額度** 與 **月／週 AI 訂閱額度（BYOT）**，轉化為像素風遊戲裡的「算力小人」，共同投票立項、雙軌接單打工，推動項目上線並透明分享收益分紅。

## 快速啟動（零依賴，開箱即玩）

```bash
npm run dev
```

啟動後在瀏覽器開啟 `http://localhost:3456`。

## 核心功能亮點

1. **即時互動像素小鎮畫布**：包含 🏭 自動工坊（API 任務）、⚔️ 懸賞工會（月/週額度 BYOT 任務）、🚀 孵化廣場（隨進度升級的工地與上線煙火）、☕ 算力宿舍。點擊建築或小人可直接互動。
2. **雙軌任務市場**：
   - **自動工坊（API 任務）**：支援**模擬模式（免 Key 即玩）**與**真實 Gemini API BYOK 模式**（Key 僅存於你自己的瀏覽器 `localStorage`，絕不經過伺服器，可真正呼叫 Gemini Flash/Pro 完成翻譯、單元測試、文件等微任務並自動驗收！）。
   - **懸賞工會（月/週額度任務）**：一鍵複製標準化 CLI / Prompt Context Pack，支援在本機用 Gemini CLI / Claude Code / Codex 或網頁訂閱完成後交卷驗收。
3. **投票立項與上線分紅**：可自由提案新項目、投票達標自動解鎖工地與雙軌任務；項目達 100% 後一鍵發布上線，觸發煙火與即時收益分紅。
4. **創作者收益看板**：即時展示平臺創作者的 4 條現金流（懸賞 10% 抽成、孵化分紅池 10% 分成、像素霓虹廣告位、外觀／Pro 訂閱）。
