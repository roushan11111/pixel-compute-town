## 第二章：完整註冊與登入流程（4 種方式）

像素算力鎮支援 **4 種不同門檻** 的進入與綁定方式，你可以依習慣任選其一。

### 方式一：遊客 Demo 秒速試玩（零門檻，3 秒開玩）

適合想先體驗完整功能、還不想註冊帳號的新手。

1. 打開官網首頁 `/` 或直接前往主應用 `/app`。
2. 系統會自動以預設的 **「創始鎮長 (Demo)」** 身分載入完整沙盒世界（內建起始算力小人、預置孵化項目、可審查的乾淨/垃圾 PR 佇列與模擬金幣）。
3. 你可以直接體驗接單、AI 擬真交付、審閱駁回垃圾 PR、投票立項、上線分紅與下載打工證 PNG。
4. 若先前已登入其他帳號，點擊右上角帳號徽章（`🧑‍💻`）開啟 **「🔐 帳號註冊與登入」** 視窗，點選 **`🎮 遊客 Demo 模式`** 即可隨時切回 Demo 帳號。

> 💡 **提示**：Demo 帳號用於公開體驗與快速測試；若想長期保存個人金幣、小人、收款錢包與分紅餘額，請使用方式二或方式三建立獨立帳號。

### 方式二：信箱＋密碼註冊登入（獨立錢包與小人隔離）

適合一般使用者與開發者建立長期獨立的個人小鎮帳本。

1. 在 `/app` 畫面右上角點擊帳號徽章（例如 `🧑‍💻 創始鎮長 (Demo)`），開啟 **「🔐 帳號註冊與登入」** 彈窗。
2. 切換至 **`✨ 免費註冊`** 分頁：
   - **顯示暱稱（選填）**：輸入你在小鎮與排行榜上的代號（最多 32 字元，例如 `CyberBuilder`）。
   - **電子信箱**：輸入有效的 Email 格式。
   - **密碼**：設定 **6 至 128 個字元** 的密碼（後端採用 Node.js 原生 `scrypt` 加鹽雜湊儲存，絕不明文存庫）。
3. 點擊送出完成註冊：
   - 系統自動簽發 7 天有效的 `HttpOnly; SameSite=Lax` HMAC-SHA256 登入憑證 Cookie。
   - 立即配發獨立起始帳本：**300G 起始金幣**、信譽分 `100`、專屬起始算力小人與獨立的 6 枚創世成就進度。
   - 你的個人金幣、小人、皮膚與提領錢包與其他玩家完全隔離，同時與全鎮共享項目池、任務市場與創世排行榜！
4. 下次造訪時，切到 **`🔑 登入帳號`** 輸入信箱與密碼點 **`🚀 立即登入`** 即可恢復所有資產。

### 方式三：GitHub / Google 一鍵 OAuth 登入

適合開發者快速同步 GitHub 頭像與帳號身分。

1. 點擊 `/app` 右上角帳號徽章，或在 `/onboard` 步驟 1 的第三方登入區，選擇：
   - **`🐙 GitHub 一鍵登入`**（導向 `/api/auth/github`）
   - **`🌐 Google 一鍵登入`**（導向 `/api/auth/google`）
2. 在 GitHub 或 Google 官方授權頁點擊同意後，系統透過 CSRF `state` 驗證回調（`/api/auth/github/callback` 或 `/api/auth/google/callback`），自動建立或登入對應的獨立帳號並導回 `/app`。

> ℹ️ 若該小鎮實例的鎮長尚未在 `.env` 設定 `GITHUB_CLIENT_ID` 或 `GOOGLE_CLIENT_ID`，系統會自動提示並導回 Demo／信箱註冊模式，不會出現報錯白屏。

### 方式四：本機一鍵安裝＋自動彈窗註冊審核流程（推薦 BYOT 玩家）

適合想把本機 **Gemini CLI / Claude Code / Codex CLI / Cursor** 算力綁定成像素小人、即時在畫布直播敲碼進度的開發者。

#### 步驟 1：選擇你的安裝入口（官網 `/` 的「複製即裝中心」）

進入官網 `/#install`，提供 **6 種平台分頁**，會自動帶入目前伺服器網址：

- **💻 Windows (PowerShell)**：
  ```powershell
  irm https://<YOUR_DOMAIN>/install.ps1 | iex
  ```
- **🍎 macOS / Linux (Bash)**：
  ```bash
  curl -fsSL https://<YOUR_DOMAIN>/install.sh | bash
  ```
- **🤖 AI 對話安裝（Antigravity / ✨ Gemini / 🧠 Claude & Cursor / 🐋 DeepSeek）**：
  點選對應分頁並按 **`📋 一鍵複製指令 / Prompt`**，直接貼進你的 AI 助手對話框。AI 會先替你公開檢視安裝腳本確認零惡意行為，再執行安裝與 `onboard`（純網頁版 AI 則會一步步引導你複製終端指令）。

#### 步驟 2：自動下載並啟動 Device Flow

腳本會在你的家目錄建立 `~/.pixelcompute/pixel-worker.mjs`（單一零依賴檔案），自動偵測你的作業系統與已安裝的本機官方 CLI（`gemini`、`claude`、`codex` 等），向小鎮申請一組 **15 分鐘有效** 的裝置授權碼（格式如 `PCT-XXXX-XX`），並自動開啟瀏覽器前往：

```text
https://<YOUR_DOMAIN>/onboard?code=PCT-XXXX-XX
```

> 💡 想先看看審核頁長什麼樣子？可直接點擊官網的 **`🔍 體驗註冊審核頁（Demo）`**（`/onboard?demo=1`）。

#### 步驟 3：在 `/onboard` 完成 3 步零信任核准

1. **檢視裝置資訊與零信任權限清單**：核對裝置名稱、OS、偵測到的 CLI 工具與四條安全承諾（不讀 Cookie、不碰 API Key、不改源碼、只傳心跳）。
2. **STEP 1 · 確認或建立小鎮帳號**：若尚未登入，可直接在頁面上免費信箱註冊、登入、GitHub/Google OAuth 或點 **`⚡ Demo 創始帳號快速綁定`**。
3. **STEP 2 · 挑選 32×32 HD 像素小人化身**：從 4 大職業（閃電工程師、首席架構師、像素美術師、工會匠人）挑選專屬像素外觀，並自訂小人暱稱（上限 32 字元）。
4. **STEP 3 · 點擊 `✅ 核准並綁定此裝置`**：
   - **一般自助模式（預設）**：立即核准！終端機的 `pixel-worker` 在 2 秒內自動收到憑證寫入 `~/.pixelcompute/config.json`，你的新小人立刻進駐小鎮上工。
   - **嚴格裝置審核模式（鎮長防刷保護開啟時）**：狀態會顯示為 **「等待鎮長人工審核 (`pending_review`)」**；待創始鎮長於管理面板點選核准後，終端輪詢即自動放行完成綁定（若遭拒絕則會明確顯示拒絕原因）。

## 第三章：完整使用流程（按角色分路線操作指南）

### 路線 A：我有閒置 API 額度（自動工坊 BYOK 掛機賺分紅）

1. **開啟零信任 BYOK 設定**：
   - 點擊 `/app` 頂部的 **`BYOK：擬真體驗`** 膠囊或右上角 **`⚙️ 設定`**，也可在「🏭 自動工坊」點 **`🔑 設定 API Key`**。
   - 選擇模型介面協議：
     - **Google Gemini API（一等公民 · 瀏覽器直連）**：預設提供 `gemini-2.5-flash`（高性價比推薦）、`gemini-2.5-pro`、`gemini-2.0-flash`。
     - **OpenAI 相容 Endpoint**：支援 OpenRouter（`https://openrouter.ai/api/v1`）、DeepSeek（`deepseek-chat`）、OpenAI（`gpt-4.1-mini`）與 **本地 Ollama**（`http://localhost:11434/v1`，本地端點免填 Key 即可直連！）。
   - 輸入你的 API Key（留空則維持免金鑰高品質擬真體驗），並設定 **「單次任務最大輸出 Token 上限」**（預設 `2048`，可調範圍 `256`–`16384`，防止帳單爆倉）。
   - 點擊 **`🔌 測試連線`** 確認暢通後，按 **`💾 儲存於瀏覽器`**（只寫入本機 `localStorage` 的 `pixel_compute_town_byok_v1`，絕不經過伺服器）。
2. **派小人接單或開啟 Auto-Pilot 自動掛機**：
   - 切換到右側 **`🏭 自動工坊`** 分頁，透過下拉選單篩選項目與狀態，挑選要出動的 API 小人（例如「快閃工坊員」或「像素美術工」）。
   - 點擊任務卡上的派工按鈕，瀏覽器將直接呼叫你的 AI 模型產出結構化交付物（如多語系 JSON、單元測試程式碼或技術文件），自動送交後端 **3 層 Proof of Accepted Work（PoAW）防作弊驗收**。
   - 想解放雙手？勾選工具列右側的 **`🤖 自動掛機`**，系統將每 **6 秒** 自動為閒置的 API 小人領取開放微任務、執行並驗收結算！
3. **檢視驗收報告與領獎勵**：
   - 驗收通過立即發放金幣、經驗值（升級還會提升體力上限）與該項目的週邊池貢獻點數，點擊已完成任務可隨時檢視完整的 PoAW 檢核明細與交付原文。
   - 小人體力耗盡時，到 **`👾 小人商店`** 分頁或 **`☕ 算力宿舍`** 幫小人點杯咖啡即可回血。

## 第五章：常見問題 FAQ

### Q1：把我的 API Key 填在自動工坊裡安全嗎？伺服器會看到嗎？
**完全不會。** 自動工坊嚴格遵守 **Zero-Trust BYOK** 原則：你的 API Key 只寫在自己瀏覽器的 `localStorage` 中，AI 推論請求直接由你的瀏覽器發往 Google Gemini、OpenRouter、DeepSeek 或本機 Ollama，小鎮後端伺服器**從未接收、記錄或中轉任何金鑰**。你也可以隨時點 **`🗑️ 清除金鑰`** 徹底抹除。

### Q2：用我的 Claude / Gemini CLI / Codex 月費訂閱參加懸賞工會，會違反官方服務條款被封號嗎？
**不會。** 像素算力鎮採用 **合規 BYOT（Bring Your Own Tool）** 模式：絕不代管帳號、絕不讀取 `~/.gemini`、`~/.claude`、`~/.codex` 或瀏覽器 Cookie、絕不架設多人共享反代池。你就像平常寫開源專案一樣，在自己電腦上合法執行官方 CLI 並親自審查後提交成果，`pixel-worker` 只負責傳送輕量工位進度心跳。

### Q3：如果有人用便宜模型寫腳本狂刷一萬個翻譯微任務，會不會把我寫核心架構的分紅稀釋光？
**數學上絕無可能。** 在 95% 實幹建設池裡，系統透過 **70/30 分桶隔離** 把核心架構池鎖定為 70%（佔總營收 66.5%），所有週邊微任務合計嚴格封頂在 30%（佔總營收 28.5%）。刷單者只會在 30% 週邊桶內互相內捲，你的核心架構分紅分毫不減；同時垃圾提交還會被 AI 盲審標紅、遭資深審閱團駁回沒收押金並觸發冷卻。

### Q4：我只提出好點子、不太會寫程式，也能分紅嗎？
